ติดตั้งเองจากหน้านี้
  • หน้าปัดรอบ + ความเร็ว แบบคลาสสิก
  • ค่าพื้นฐาน 10 อย่าง: น้ำ, ไฟ, ภาระ, คันเร่ง, อากาศ, MAP, น้ำมันเครื่อง, จุดระเบิด, MAF, น้ำมัน
  • เตือนน้ำร้อน · ไฟอ่อน · รอบสูง
  • อ่านรหัสปัญหา (DTC)
  • หรี่จออัตโนมัติ · โหมดกลางคืน
  • อัปเดตออนไลน์ผ่าน Wi‑Fi

ทุกอย่างในรุ่นฟรี และ…
  • หน้า 4 เกจ และกราฟย้อนหลัง
  • หน้าปัดเพิ่ม 3 แบบ: LED · เรือง · สปอร์ต (มีเข็มค้างค่าสูงสุด)
  • ค่าครบ 43 อย่าง ที่รถรองรับ
  • ล้างรหัสปัญหา (ดับไฟเช็คเอนจิน)
  • โหมด HUD สะท้อนกระจกหน้ารถ
  • ดักฟัง CAN · ฟังก์ชันใหม่ในอนาคต

ติดตั้งรุ่นฟรีผ่านเบราว์เซอร์

ไม่ต้องลงโปรแกรม ใช้เวลาประมาณ 2 นาที

บอร์ด ESP32‑2432S028Rหรือที่เรียกว่า "CYD" จอ 2.8" สีเหลือง
สาย USB ที่ส่งข้อมูลได้สายชาร์จอย่างเดียวจะมองไม่เห็นบอร์ด
Chrome หรือ Edge บนคอมWindows / Mac / Linux (มือถือใช้ไม่ได้)
เบราว์เซอร์นี้ติดตั้งไม่ได้ · ใช้ Chrome หรือ Edge บนคอมพิวเตอร์ ต้องเปิดหน้านี้ผ่าน https
กดแล้วเลือกพอร์ตของบอร์ด (เช่น "USB Serial" / "CH340") → ติ๊ก Erase device → Install
ถ้าไม่เจอพอร์ต: ลองสายเส้นอื่น หรือติดตั้งไดรเวอร์ CH340
ปรับทัชครั้งแรกเปิดเครื่องแล้วแตะเป้า 4 มุมตามจอ
จับคู่ ELM327ตั้งค่า → การเชื่อมต่อ → ค้นหา → แตะชื่อ OBDII / ELM327
เสียบ ELM327 ที่ช่อง OBD ใต้คอนโซล แล้วบิดกุญแจเกจจะเชื่อมต่อและแสดงค่าเอง ยังไม่มีรถ? กด "ข้าม" ที่หน้าแรกเพื่อดูโหมดเดโม
